# Implementation Plan

## Phase 1: Foundations — complete

- Preserve and document the official UCI source.
- Establish output, QA, documentation, test, and reporting directories.
- Build the configurable transaction-cleaning and KPI pipeline.
- Define synthetic portfolio, milestone, risk, issue, dependency, and action data.
- Document source provenance, KPI rules, SOP, assumptions, and test plan.

## Phase 2: Data execution and controls — next

- Run the full source through the pipeline and retain clean CSV, KPI tables, QA evidence, reconciliation, exceptions, and run log.
- Add malformed-source and zero-denominator test cases.
- Validate transaction totals, portfolio integrity, overdue actions, and risk scores.

## Phase 3: Executive reporting

- Create the required Excel command centre from verified outputs.
- Build the ten-slide management review using the same figures.
- Produce the executive decision memo with evidence, owners, dates, success measures, and limitations.
- Reconcile all reporting artifacts before portfolio hand-off.
